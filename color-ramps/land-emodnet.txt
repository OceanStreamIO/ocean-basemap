# Land ramp inspired by the EMODnet World Base Layer.
#
# The lowland stops are a curated, subdued sage-to-beige treatment of the
# Cabo Espichel reference, not a recovered EMODnet lookup table. Sampling
# already-shaded imagery by elevation cannot separate illumination and land
# cover from the underlying palette. Keep these tints near-neutral so height
# alone does not turn every lowland, including deserts, into green vegetation.
#
# Below 800 m, slightly warmer coastal greys and lighter, less brown hills
# replace the previous Europe-sampled ramp. The stops from 800 m up retain
# the existing upland, rock and snow colours; ice has its own masked ramp.
#
# Use with LAND_SHADING in pipeline/hypsometric.py. Limiting highlights is
# essential: strong lighting clips pale colours to white and loses their hue.
# This revision needs visual review on the data host before promotion; local
# validation uses synthetic terrain, not a rebuilt Cabo Espichel tile.
#
